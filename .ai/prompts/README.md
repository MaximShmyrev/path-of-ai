# Промпты воркфлоу (Spec-Driven Development)

Шаблоны для управляемой разработки с LLM. Подход: **сформулировать → дать
контекст → спека → план → улучшить план → итерации → тест → аудит**
(7 шагов «Как заставить LLM делать правильно»).

Каждый файл — самодостаточный промпт. Скопируйте его содержимое в чат любого
инструмента (Claude Code, Codex, Cursor), заполнив плейсхолдеры `<...>`.

| # | Файл | Шаг | Что делает |
|---|------|-----|-----------|
| 1 | [1-task.md](1-task.md) | Сформулировать задачу + дать контекст | Шаблон постановки задачи: концепция, правила, сценарии, критерии |
| 2 | [2-spec.md](2-spec.md) | Составить спецификацию | Из задачи → спека: архитектура, тесты, измеримые критерии |
| 3 | [3-plan.md](3-plan.md) | Сделать план | Из спеки → поэтапный план с оценками, под TDD |
| 4 | [4-improve-plan.md](4-improve-plan.md) | Улучшить план | Аудит плана: покрывает ли задачу на 100 % |
| 5 | [5-implement.md](5-implement.md) | Двигаться итерациями + тестировать | Выполнение плана этап за этапом по TDD |
| 6 | [6-audit.md](6-audit.md) | Делать аудит | Финальная проверка по Definition of Done |

## Артефакты

Промпты просят LLM создавать рабочие файлы прямо в проекте:

- `SPEC.md` — спецификация (шаг 2)
- `PLAN.md` — план разработки (шаги 3–4)
- changelog'и — внутри `SPEC.md` и `PLAN.md`

Жёсткой папки `docs/` нет: структуру создаёт LLM по промпту.
